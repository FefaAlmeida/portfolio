# Landing V2

Abra `index.html` diretamente ou `/demos/landing-v2/index.html` no servidor do portfólio. A V1 permanece em `/demos/landing/index.html`.

HTML + Tailwind compilado, CSS e JavaScript local, sem API ou CDN.

- **Projetos:** HTML, estilos, conteúdo e mídias da versão original. Carrossel, modais, galerias, vídeo e navegação por teclado preservados.
- **Extracurriculares:** mantém a linha do tempo alternada, fotos, datas, papéis e resultados. Textos condensados; removidos links provisórios, categorias redundantes, legendas repetidas e a ilustração provisória.
- **Demais áreas:** apresentação direta, uma foto, biografia em três parágrafos, seção Educação com o técnico no SENAI, reconhecimentos em lista e rodapé com o GitHub real. Sem estatísticas decorativas, slogans repetidos, adesivos ou formulário sem destino.
- Modo escuro persistente, preferência inicial do sistema, menu mobile, link para pular conteúdo, movimento reduzido e foco restaurado ao fechar modais.

Não há e-mail pessoal confirmado no conteúdo disponível; nenhum contato foi inventado. O conteúdo está em português.

Para recompilar o Tailwind, execute a partir de `frontend`:

```sh
node public/demos/landing-v2/build.mjs
```
